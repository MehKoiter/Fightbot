FightBot v1.0.0 - Modular Architecture Release

This is the first stable release of the refactored FightBot with modular architecture
and real UFC data fetching capabilities.

CORE FEATURES:
- Dependency injection based modular architecture
- Real-time UFC event data scraping
- Fighter statistics lookups
- Command handling with error recovery
- Replit deployment ready

COMMANDS:
1. /fight
   - Shows upcoming UFC event
   - Displays main card and preliminary card
   - Shows fight order and title fights
   - Includes event date and venue

2. /fighter [name]
   - Displays fighter statistics
   - Shows record, physical stats
   - Lists recent fights
   - Handles missing data gracefully

3. /info
   - Shows bot information
   - Lists available commands
   - Displays bot version

TECHNICAL SPECS:
- Node.js >= 16.9.0
- ESM modules throughout
- Discord.js v14
- Axios for HTTP requests
- Cheerio for HTML parsing
- Built-in caching system

DEPLOYMENT:
- Replit configuration included
- Environment variables documented
- Development/Production command deployment

This version serves as a stable base for future enhancements while
maintaining core UFC event tracking functionality.

Known limitations:
- Fighter search needs optimization
- Caching is memory-only
- No persistent storage yet
